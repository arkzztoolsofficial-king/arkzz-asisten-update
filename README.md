✨ Fitur Utama

🤖 Artificial Intelligence

- Asisten AI untuk menjawab pertanyaan.
- Sistem pembelajaran AI menggunakan database pengetahuan.
- Integrasi Gemini melalui Floating Browser.
- Crop Text menggunakan teknologi OCR.
- Mengirim hasil OCR langsung ke Gemini.
- Copy hasil pengenalan teks.

💬 Communication

- Chat All untuk komunikasi antar pengguna.
- Direct Message untuk percakapan pribadi.
- Status Online dan Offline.
- Notifikasi pesan masuk.
- Indikator jumlah pesan belum dibaca.
- Alias Kontak untuk mengatur nama kontak.
- Copy, Edit, dan Delete pesan.
- Delete for Me dan Delete for Everyone.

👤 User Profile

- Profil pengguna.
- Mengubah nama tampilan.
- Mengganti foto profil.
- Avatar otomatis berdasarkan huruf pertama nama.
- Sinkronisasi profil dengan Chat All dan Direct Message.
- Informasi akun dan statistik permainan.
- Pengaturan privasi profil.

🎮 Mini Games

- Tic Tac Toe.
- Tic Tac Toe Online Multiplayer.
- Memory Match.
- Animasi permainan interaktif.
- Sinkronisasi permainan multiplayer.

🛠️ Productivity Tools

- Calculator.
- Notes dengan penyimpanan Firebase.
- Clock Widget.
- Floating Browser.
- Crop Copy.
- Crop Text.

🎨 Personalization

- Dark Interface.
- Custom Accent Color.
- Animasi antarmuka.
- Tampilan yang menyesuaikan warna aksen pilihan pengguna.

🔥 Cloud Integration

ARKZZ ASISTEN menggunakan Firebase untuk mendukung fitur yang membutuhkan sinkronisasi data.

Teknologi yang digunakan:

- Firebase Authentication.
- Firebase Realtime Database.
- Firebase Cloud Messaging.
- Firebase Storage.
